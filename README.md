# YICGG 2026 新生宣讲

这是 YICGG 2026 新生进班宣讲的静态网站发布目录。

公开访问地址：<https://asl-bot.github.io/yicgg-2026-welcome/>

## 安全与隐私

- 页面为纯静态单页，不包含后端服务、账号系统或数据收集。
- 字体、图片和脚本全部内嵌，不加载第三方代码或统计工具。
- 内容安全策略禁止网络请求、表单提交、iframe、插件和外部资源。
- 页面与 `robots.txt` 请求搜索引擎不要收录；知道链接的人仍可直接访问。
- GitHub Pages 强制使用 HTTPS。
